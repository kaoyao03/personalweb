Project 1: About Me HTML Page

This project is titled “About Me HTML Page”. It showcases a personal narrative formatted and styled using HTML elements. The main goal was to apply all fundamental HTML tags as covered in our materials, including headings, paragraphs, lists, links, images, and text formatting tags, all while keeping the layout clean and visually appealing.

The page features my picture, a custom background color and background image with specific settings like no-repeat, position, and fixed attachment. I also styled the image size appropriately and used a modern, readable font to ensure the content stands out and looks professional.

This site was built from scratch and saved as aboutme.html, following all technical instructions. It demonstrates my understanding of HTML structure and aesthetics.
